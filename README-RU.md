# Сервер «Неоновых башен» — 24/7 навсегда

Этот комплект поднимает **твой собственный игровой сервер**, который работает
круглосуточно и не зависит ни от какой платформы. Один раз ставишь — и игроки
из любых городов (Псков, Махачкала, кто угодно) нажимают «Искать» и попадают
в один и тот же матч.

## Как это работает

- Сервер — socket.io-процесс на Bun, один порт: **TCP 3003**.
- Активные матчи сохраняются на диск каждые 5 секунд: даже после выключения
  сервера бой продолжится с того же места, а игроки вернутся автоматически.
- Персональные данные не собираются и не хранятся: только ники и игровые действия.
- Встроенная защита от падений: systemd перезапускает сервер за 3 секунды.

## Вариант 1 — бесплатно навсегда (Oracle Cloud Free Tier)

1. Зайди на `oracle.com/cloud/free` и зарегистрируйся (для проверки просят
   банковскую карту, но деньги не списывают — тариф Always Free).
2. Создай инстанс: **Ubuntu 22.04**, shape **Always Free Ampere A1**
   (поставь 2–4 OCPU), любой регион.
3. Открой порт 3003: Networking → Virtual Cloud Network → твоя сеть →
   Security Lists → **Add Ingress Rule**: Source `0.0.0.0/0`, протокол TCP,
   Destination Port `3003`.
4. Подключись к серверу: `ssh ubuntu@АЙПИ_СЕРВЕРА`
5. Закачай папку комплекта со своего компьютера:
   `scp -r neon-towers-server ubuntu@АЙПИ_СЕРВЕРА:~`
6. На сервере: `cd ~/neon-towers-server && sudo bash install-ubuntu.sh`
7. Готово! В игре укажи адрес `http://АЙПИ_СЕРВЕРА:3003`

## Вариант 2 — любой платный VPS (150–300 ₽/мес)

То же самое: арендуй самый дешёвый Ubuntu-сервер (timeweb, aeza, beget — любой),
открой порт 3003 в панели файрвола, закачай папку по `scp` и запусти
`sudo bash install-ubuntu.sh`.

## Вариант 3 — Docker (одна команда)

Если на машине есть Docker:

```
docker compose up -d --build
```

Снапшоты матчей хранятся в томе `neon-data`, переживают пересоздание контейнера.

## Как подключить игру к серверу

В игре: **Меню → «Адрес игрового сервера»** → вписать `http://АЙПИ:3003` →
Сохранить. **Все игроки вписывают один и тот же адрес** — после этого кнопка
«Искать» ищет соперников на твоём сервере.

Если хочешь вернуть встроенный сервер — просто очисти поле адреса.

## Если что-то пошло не так

- Проверить живость: открой `http://АЙПИ:3003/socket.io/?EIO=4&transport=polling`
  — должен показаться код вида `0{"sid":...}`.
- Перезапустить: `sudo systemctl restart neon-towers`
- Посмотреть логи: `journalctl -u neon-towers -f`
- Матчи после перезапуска восстановятся сами (снапшоты в `/opt/neon-towers/db`).

## Технические детали

- Нужен только порт **TCP 3003**.
- Автостарт при включении машины, авторестарт при падении (Restart=always).
- Файлы ставятся в `/opt/neon-towers`, снапшоты — в `/opt/neon-towers/db`.
- Обновил игру? Замени файлы `mini-services/game-server/index.ts` и
  `src/lib/game/shared.ts` и выполни `sudo systemctl restart neon-towers`.
