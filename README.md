# NeonTowers — игровой сервер 24/7

Комплект сервера игры «Неоновые башни» для деплоя (Railway / VPS / Docker).

Полная инструкция: [README-RU.md](README-RU.md)

Быстрый деплой на Railway: New Project → GitHub Repository → этот репозиторий
(Railway сам соберёт Dockerfile), затем Settings → Networking → Generate Domain.

Порт: TCP 3003.
